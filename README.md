# 📚 API de Livraria

Essa API foi desenvolvida para gerenciar um sistema de livraria, incluindo operações de cadastro, busca, atualização e exclusão de **livros** e **autores**. A aplicação foi construída com **Node.js**, **Express**, **Mongoose** e **MongoDB**.

## 🚀 Tecnologias Utilizadas

- **Node.js**: Ambiente de execução para JavaScript no servidor.
- **Express**: Framework para construção de APIs.
- **Mongoose**: ODM (Object Data Modeling) para MongoDB e Node.js.
- **MongoDB**: Banco de dados NoSQL para armazenamento de livros e autores.

## 🔧 Funcionalidades

### 📖 Livros
- **Cadastro de livros**: Permite o registro de novos livros no banco de dados.
- **Busca de livros**: Possibilita a busca de livros por diversos critérios, como título, autor e gênero.
- **Atualização de livros**: Permite a modificação de informações de livros já cadastrados.
- **Exclusão de livros**: Realiza a remoção de livros do banco de dados.

### ✍️ Autores
- **Cadastro de autores**: Permite o registro de novos autores no banco de dados.
- **Busca de autores**: Permite a busca de autores por nome.
- **Atualização de autores**: Permite a modificação de informações de autores.
- **Exclusão de autores**: Realiza a remoção de autores do banco de dados.
